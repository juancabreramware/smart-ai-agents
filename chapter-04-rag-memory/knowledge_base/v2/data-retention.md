# Northstar Cloud - Data Retention

<!-- fact:application_log_retention_days -->
Production application logs are retained for 14 days.

<!-- fact:backup_retention_days -->
Backups are retained for 45 days.

<!-- fact:deleted_account_retention_days -->
Deleted-account data is retained for 7 days after account closure before permanent deletion.

<!-- fact:enterprise_audit_log_retention_days -->
Enterprise audit logs are retained for 365 days.
