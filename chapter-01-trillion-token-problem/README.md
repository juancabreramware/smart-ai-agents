# Chapter 1 — The Trillion-Token Problem
## Why Smart Agent Design Is Now a Board-Level Decision

Chapter 1 establishes the economic problem that motivates the rest of the book: intelligent systems often spend inference repeatedly on work whose procedure has already been discovered.

This chapter is intentionally **not a code chapter**. Its role is to establish the executive and architectural case for treating repeated reasoning as an engineering and economic design decision.

## Core idea

> **An intelligent system should not repeatedly pay an intelligence premium for work it has already learned how to perform.**

The chapter distinguishes the cost of acquiring intelligence from the lifetime cost of repeatedly invoking it. It also introduces the broader economic framing that is developed in Appendix A.
